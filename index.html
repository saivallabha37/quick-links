WHY I BUILT THIS

Ever spent more time choosing your stack
than building the actual thing?

Yeah. Me too.

I kept running into the same problem.

I wanted to build modern websites — the kind that feel polished, interactive, and actually fun to use.

But before I could build anything, I'd end up asking:

  • ? Which UI library?
  • ? Which animation library?
  • ? Which database?
  • ? Which backend?
  • ? Which AI tool?
  • ? Which deployment platform?

And then came the rabbit hole.

One website led to another.

One GitHub repo led to another.

20 browser tabs later, I was still deciding what stack to use.

I wasn't building anymore. I was choosing.

So I started collecting the tools I actually liked using — and more importantly, when and why I'd use them.

Quick Links grew from that idea.

It's not meant to be another giant directory of developer resources.

It's my decision-making toolbox.

A place where you can come in with:

YOU ENTER WITH
“I want to build a 3D website.”
↓
YOU LEAVE WITH
“Okay. Spline + Three.js + Motion. Let's build.”

So if you've ever been stuck wondering “what should I use?”

You're probably exactly who I built this for. ⚡

Less time choosing.
More time building.
Now thank me later.
