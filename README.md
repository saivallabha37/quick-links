# ⚡ Quick Links

> **Build faster. Choose smarter.**

A personal developer toolbox for discovering, comparing, and quickly accessing
frameworks, libraries, platforms, developer tools, design resources, and
workflows — all in one place.

Instead of keeping hundreds of browser bookmarks or repeatedly searching for
the right tool, Quick Links gives me a single dashboard where I can quickly
decide what to use for a project.

---

## ✨ What is Quick Links?

Quick Links is a searchable, categorized collection of resources that I use
(or want to explore) while building software.

It is designed around a simple question:

> **"I'm building something — what should I use?"**

For example:

- Need beautiful React components? → **shadcn/ui / React Bits / Aceternity UI**
- Need animations? → **Motion / GSAP / Anime.js**
- Need 3D? → **Spline / Three.js / React Three Fiber**
- Need an AI API? → **OpenAI / Gemini / Hugging Face**
- Need authentication? → **Clerk / Better Auth**
- Need a database? → **Supabase / MongoDB / PostgreSQL**
- Need deployment? → **Vercel / Render / Railway**
- Need design inspiration? → **Awwwards / Godly / Mobbin**
